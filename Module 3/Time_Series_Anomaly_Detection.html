Fifteen lines, the whole module

import pandas as pd
from statsmodels.tsa.seasonal import MSTL
from sklearn.ensemble import IsolationForest

x = pd.read_csv(NAB_URL, parse_dates=["timestamp"], index_col=0)["value"]

res = MSTL(x, periods=(48, 336)).fit().resid           # Part A
F = pd.DataFrame({"lag1d": x - x.shift(48),            # Part B
                  "lag1w": x - x.shift(336),
                  "m1d": x.rolling(48).mean(),
                  "s1d": x.rolling(48).std()}).dropna()

z = ((x - x.rolling(336).mean()) / x.rolling(336).std()).abs()   # Part C
iso = IsolationForest(n_estimators=200, random_state=0).fit(F)
score = -iso.score_samples(F)

from dtaianomaly.evaluation import VolumeUnderPR          # Part D
VolumeUnderPR().compute(y_true, score)

Takeaways

  • Normal is a model. Trend, season and residual say what the series would have done; the residual is where anomalies live.
  • Context belongs in the features. Lags and trailing rolling statistics, built from the past only, carry the weekday and the hour.
  • The input matters more than the algorithm. A forest on the raw count is no better than a z-score; on window features it wins (AUC-PR 0.48 vs 0.12).
  • Judge by events, honestly. Report event recall and VUS-PR, never point-adjusted F1 alone.
